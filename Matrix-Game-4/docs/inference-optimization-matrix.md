# 推理优化实验数据登记表

> 配套 [inference-optimization-survey.md](inference-optimization-survey.md)。
> 每跑完一组实验就在此追加一行；**同一会话内产生的基线与其变体**必须相邻记录，
> 避免跨会话的随机种子差异污染对比。

## 记录口径

- `chunk_ms` / `FPS`：144 帧稳态，`perf_harness.py`
- `lag_ms`：交互链路，`play_rendered.py` 状态栏
- `LPIPS`：相对同会话基线，均值 / 最差 5%
- `flicker`：时序稳定性指标，增幅超过 15% 视为不通过
- 崩溃：记录 `0xC0000005` 次数与机器重启次数
